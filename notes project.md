## Rule

Each component has:

1. One base class
2. Approved variant classes
3. Automatic mobile, tablet and desktop behavior
4. Brand colors supplied through tokens

Example:

```css
.hero {}

/* Structural variants */
.hero--split {}
.hero--emergency {}
.hero--project {}

/* Responsive behavior */
@media (min-width: 768px) {}

@media (min-width: 1024px) {}
```

Variants change the component’s structure or purpose. Breakpoints control how it responds to screen size. Themes change its colors and typography.

Each master template selects from the approved variants. Client builds should not create new component variants unless you intentionally add one to the master system.
