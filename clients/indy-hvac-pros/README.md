# Indy HVAC Pros: web brand files (demo company)

Final logo direction: **A, house with heat (flame) and cool (snowflake)**. Chosen 2026-10-01.
Made by `docs/brand/clients/indy-hvac-pros/make_final_logo.py`. Don't edit these by hand; change the script and re-run it.
All logo text is converted to outlines, so the files display the same everywhere without the font.

| File | Use |
|---|---|
| `logo-horizontal-light.svg` | Website header on white (32–36px tall). No descriptor. |
| `logo-horizontal-dark.svg` | Website footer on navy. No descriptor. |
| `logo-full-light.svg` / `logo-full-dark.svg` | Large placements only (48px+ tall, print): adds "HEATING & COOLING · INDIANAPOLIS" |
| `logo-mark.svg` | House mark alone, 48px and up |
| `logo-mark-compact.svg` | Bolder house mark for 16–32px |
| `favicon.svg` | Browser tab icon; turns blue in dark mode |
| `favicon-32.png` | Favicon fallback for older browsers |
| `apple-touch-icon-180.png` | iPhone home-screen icon (white background) |
| `og-1200x630.png` | Link preview image for texts and social media |
| `hero.webp` | Hero background, 768px and up (16:9, 1920 × 1080). AI-generated for this demo. |
| `hero-mobile.webp` | Hero photo band on phones (4:3, 1200 × 900). Same image, cropped. |
| `area-indianapolis.webp` | Service area section: downtown skyline at dusk (3:2). Owner-supplied; license to confirm. |

Hero overlay and measured contrast: `docs/group-a-style-brief.md` §6.

Colors: Brand Blue `#2457FF`, Navy `#0B0F1A`, White knockout, Blue on Dark `#93A9FF` (accents on navy only).
